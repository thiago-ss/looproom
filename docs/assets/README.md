# Looproom launch assets

| Asset | Use |
|---|---|
| [Hero](looproom-hero-v1.png) | README banner; linked-loop sculpture and lowercase wordmark |
| [Community poster](looproom-social-v1.png) | Square launch artwork for X/Reddit |
| [Prompt set](prompts.json) | Exact generation prompts and mode |

Both assets were generated with the built-in **imagegen** tool, then inspected for text, palette and composition. The historical Looproom sculpture was an identity reference for the hero; the hero was an identity reference for the companion poster. Neither image depicts the actual application or a product screenshot.

The deep plum field, citron/lavender/blue loops, individual spheres and peach gate extend the existing project identity. The gate represents human merge approval. This is project artwork distributed with Looproom under its MIT license; preserve applicable project notices. Font-like lettering is raster art, not a bundled font file. Actual IBM Plex font files retain their OFL notice.

README structure was researched from [Zed](https://github.com/zed-industries/zed), [Uptime Kuma](https://github.com/louislam/uptime-kuma), [autoresearch](https://github.com/karpathy/autoresearch) and [RAGFlow](https://github.com/infiniflow/ragflow). Their navigation/quick-start patterns informed original writing; no branding, slogans, adoption numbers or artwork were copied.
