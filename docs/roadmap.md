# Roadmap

This is a direction for community work, not a release-date commitment. Check existing issues before starting a large change.

## Next

- Complete representative browser baselines, including rich Goal/chat timing, and preserve source-bound reports.
- Validate multiple simultaneous native task/check/review/PR pipelines on real repositories.
- Improve macOS packaging and replace the deprecated verification sandbox runner.
- Expand keyboard, contrast and reduced-motion checks across real screens.
- Make first-run diagnostics and recovery easier to understand.

## Research

- Generalize protected experiment harnesses beyond the current refresh recipe. Keep evaluator/workload identity fixed and distinguish claims from coordinator measurements.
- Benchmark Jev retrieval against the implemented SQLite FTS5 baseline for relevance, latency and token cost.
- Improve semantic contradiction review and reconciliation between runtime memory and existing project wikis.

## Principles

A judge response must not invent missing access. A benchmark must not weaken its evaluator to claim a win. Source-linked memory must retain uncertainty. Every PR merge stays human-approved for its current revision. When no useful next task is supported by evidence, waiting is a valid outcome.
