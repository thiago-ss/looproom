# Historical orb avatars

`judge-idle.png` is a transparent 96 × 96 capture of the installed Orbkit
Shdr13 plasma globe in its idle state, rendered at 64 CSS pixels and 1.5 DPR.
It keeps the judge's original material in conversation history without creating
one WebGL context per message. Current activity and the agent room retain live
Orbkit rendering and idle/thinking states.

Source: https://orbkit.zzzzshawn.cloud/r/shdr-13.json
Installed renderer: `src/components/ui/shdr-13.tsx` and `orbkit-core.tsx`.
